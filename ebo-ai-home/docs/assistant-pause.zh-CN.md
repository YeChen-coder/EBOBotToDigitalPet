# Dashboard 的 AI 助手开关

在本地 Dashboard 的“AI 助手开关”区域使用两个按钮：

- **暂停 AI 助手**：结束正在连接、对话或保存记忆的 AI 会话，停止 AI 发声，暂停语音唤醒和人脸主动招呼。适合与家人通话时使用。
- **恢复 AI 助手**：重新允许有效语音或手动操作开启新会话。旧会话、缓存声音和迟到的 WAV 回退不会重新播放。

“结束会话”只结束当前一轮，随后仍可被语音唤起；“暂停 AI 助手”会保持暂停，直到手动恢复。

开关只控制 Realtime assistant 的 AI 能力。摄像头、Engine、麦克风传输、Frigate、Home Assistant 和家人通话继续运行。按钮操作不会停止或重启容器。

暂停状态原子保存到持久化的 `/data/assistant-control.json`，页面刷新、assistant 重启或重建后继续生效。恢复只重开 AI 能力，不主动重放之前的对话。需要自定义保存路径时设置 `EBO_ASSISTANT_CONTROL_PATH`。

暂停也会取消会话记忆总结和正在执行的后台记忆整理，不再启动新的模型任务。已经保存的逐字记录和记忆文件保留；被暂停的本轮不强制生成新摘要。暂停前已经发出的同步转写请求可能完成，但其结果被失效处理，不能重开会话或发声。

后端提供带控制 token 的 `POST /assistant/pause` 和 `POST /assistant/resume`。Dashboard 使用本地服务代理及同源 CSRF 验证，凭据不进入网页。暂停期间 `/session/start` 返回 `409 assistant_paused`。现有云端部署尚未升级到当前家庭会话框架，因此此开关用于当前本地运行模式。

验证于 2026-10-01：对实机正在进行的 AI 会话发出暂停，请求约 28ms 返回确认；随后 Realtime 连接关闭，语音唤醒停止，摄像头和音频传输仍正常；操作前后全部业务容器 ID 和启动时间一致。单独重启 assistant 验证暂停状态仍保留，之后恢复成功。28ms 是请求确认耗时，不是实测扬声器停止耗时。

自动测试覆盖所有会话阶段、禁止手动 / 语音 / 人脸绕过暂停、状态持久化、连接取消、总结取消、后台整理取消、已送出的音频停止，以及恢复后丢弃旧音频回退。

完整 assistant 测试 92 项、diagnostics 测试 124 项均通过。收尾时按用户要求保留 `enabled=false`；之后另一个整体关停任务停止了 Dashboard 和业务容器，未为复核而重新启动它们。下次启动项目后，AI 仍需在 Dashboard 手动恢复。
